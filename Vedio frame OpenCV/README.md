# 视频插帧工具

一个基于 Python 和 OpenCV 开发的视频插帧工具，用于提高视频的流畅度。

## 功能特性

- 🎬 **支持多种视频格式**：MP4、AVI、MOV、MKV、WMV 等
- ⚡ **多种插帧方法**：
  - 线性插值（Linear Interpolation）
  - 基于运动估计的插值（Motion Estimated Interpolation）
- 📊 **灵活的参数设置**：支持 2-10 倍插帧倍数
- 🖼️ **视频预览**：实时预览视频第一帧
- 📈 **实时进度显示**：直观展示处理进度
- 🔊 **自动音频处理**：保留原始视频的音频轨道
- 🎨 **友好的 GUI 界面**：简洁易用的图形用户界面

## 技术栈

- **Python 3**：主要开发语言
- **OpenCV (cv2)**：视频处理和计算机视觉算法
- **Tkinter**：GUI 界面开发
- **PIL/Pillow**：图像处理和 GUI 显示
- **FFmpeg**：音频处理和视频合成
- **NumPy**：数值计算和数组操作

## 安装与使用

### 环境要求

- Python 3.6 或更高版本
- 足够的系统内存和磁盘空间（取决于视频大小）

### 依赖安装

1. 安装 Python 依赖包：
```bash
pip install opencv-python numpy pillow
```

2. **FFmpeg 配置**：
   - 确保 `ffmpeg.exe` 已放在项目目录下
   - 如未提供，需自行下载并放置到项目根目录

### 使用方法

#### 方法一：直接运行脚本

```bash
python video_interpolation_tool.py
```

#### 方法二：使用可执行文件

直接运行 `dist/视频插帧工具.exe`（如已生成）

## 功能说明

### 1. 视频选择

- **输入视频**：点击浏览按钮选择要处理的视频文件
- **输出路径**：点击浏览按钮选择处理后视频的保存位置

### 2. 参数设置

- **插帧倍数**：设置视频的插帧倍数（2-10倍）
- **插帧方法**：
  - **Linear**：线性插值，速度快但效果一般
  - **Motion Estimated**：基于运动估计的插值，效果更好但处理时间较长

### 3. 视频预览

选择视频后，会自动显示视频第一帧作为预览

### 4. 开始处理

点击"开始插帧"按钮开始处理视频

### 5. 处理进度

- 进度条实时显示处理进度
- 状态标签显示当前处理状态
- 可随时点击"取消"按钮停止处理

## 技术实现细节

### 插帧算法

1. **线性插值**：
   ```python
   def linear_interpolation(self, frame1, frame2, alpha):
       return cv2.addWeighted(frame1, 1 - alpha, frame2, alpha, 0)
   ```
   - 简单快速，通过加权平均计算两帧之间的过渡帧

2. **基于运动估计的插值**：
   - 使用 `cv2.calcOpticalFlowFarneback` 计算光流
   - 根据像素运动轨迹生成中间帧
   - 效果更好，尤其适合运动场景

### 多线程处理

- 使用 `threading.Thread` 在后台处理视频，避免 GUI 界面卡顿

### 音频处理

- 使用 FFmpeg 提取原始视频音频并添加到处理后的视频中
- 支持各种音频格式

## 注意事项

1. **处理时间**：
   - 处理时间取决于视频长度、分辨率和插帧倍数
   - 高分辨率、高倍数插帧可能需要较长时间

2. **系统资源**：
   - 建议在处理大视频时关闭其他占用大量资源的程序
   - 运动估计插值方法会消耗更多 CPU 和内存资源

3. **磁盘空间**：
   - 确保有足够的临时存储空间（处理过程中会生成临时文件）
   - 输出视频文件大小会比原始视频大（约为原始大小 × 插帧倍数）

4. **视频格式**：
   - 部分特殊编码的视频可能不支持
   - 建议使用常见的 MP4、AVI 格式
